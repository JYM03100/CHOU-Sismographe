\# CHOU‑Sismographe   



Agent d’analyse de métadonnées sociales comparant deux fenêtres temporelles :

\- \*\*Fenêtre historique\*\* (2016–2019)

\- \*\*Fenêtre actuelle\*\* (2026 → présent)



Le CHOU‑Sismographe détecte :

\- pics

\- ruptures

\- cycles

\- similarités fractales

\- dynamiques temporelles

\- résonances entre fenêtres



Il génère :

\- visualisations statiques

\- visualisations interactives

\- rapports textuels

\- synthèses proportionnées

\- exports structurés



Il n’analyse \*\*aucun contenu textuel\*\*, \*\*aucune donnée personnelle\*\*.

Il ne manipule que des \*\*métadonnées agrégées\*\*.

\---



\# 🧠 Intention du projet



Créer un \*\*instrument de lecture proportionnée\*\* des dynamiques sociales :

\- sans jugement

\- sans interprétation politique

\- sans analyse de contenu

\- sans extraction de données personnelles



Le CHOU‑Sismographe est un \*\*outil pédagogique\*\*,

permettant de visualiser des \*\*mouvements\*\*, des \*\*cycles\*\*, des \*\*ruptures\*\*,

sans jamais analyser les intentions des individus.



\---



\# 🌀 Logique d’emploi



1\. Charger les deux fenêtres temporelles

2\. Normaliser les timestamps en UTC

3\. Détecter les IP étrangères (étoiles + drapeaux)

4\. Calculer les indices CHOU

5\. Détecter les ruptures

6\. Analyser les fractales

7\. Comparer les fenêtres

8\. Générer les visualisations

9\. Produire la synthèse proportionnée

\# 🗣 Place des avis utilisateur (texte / voix)



Le système accepte :

\- des commandes textuelles

\- des commandes vocales (Android / Windows 12)

\- des avis utilisateur

\- des corrections

\- des interprétations personnelles



L’utilisateur peut :

\- demander une analyse

\- demander une visualisation

\- demander une synthèse

\- poser des questions

\- commenter les résultats



Le CHOU‑Sismographe \*\*ne juge pas\*\* les avis utilisateur.

Il les intègre dans une \*\*fenêtre de dialogue proportionnée\*\*,

via Copilot ou via l’interface Windows 12 / Android.
