# PUBLICATION

## ✔ Vérifier l’état du dépôt

git status


## ✔ Ajouter les fichiers modifiés

git add .


## ✔ Committer

git commit -m "Mise à jour du code et de la documentation"


## ✔ Pousser vers GitHub
git push origin main


## ✔ Créer une release (optionnel)

Sur GitHub :

1. Aller dans **Releases**
2. Cliquer sur **Draft a new release**
3. Choisir un tag (ex : `v1.0.0`)
4. Ajouter un titre + description
5. Publier

## ✔ Conseils pour les versions

- Utilisez `v1.0.0` pour la première version stable  
- Utilisez `v1.1.0` pour les nouvelles fonctionnalités  
- Utilisez `v1.0.1` pour les corrections mineures
